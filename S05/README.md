# Полка · Мини-маркет

ДЗ №5 по стилизации React. В каталоге есть поиск, категории, корзина и переключение между светлой, тёмной и шалфейной темами. По ссылке «UI-кит» можно посмотреть все варианты и размеры кнопки. Каталог и добавление в корзину работают с локальными данными и имитируют загрузку.

## Запуск

Нужен Node.js 22.12+ (также подходит 20.19+ из ветки 20). Выполни команды из папки `S05`.

```bash
npm ci
npm run dev
```

Проверка и просмотр production-сборки.

```bash
npx playwright install chromium --only-shell
npm test
npm run build
npm run preview
```

## styled-components и CSS Modules

В «Полке» styled-components позволяют хранить описание внешнего вида рядом с реализацией компонента. Типизированная тема даёт подсказки для цветов, отступов и радиусов прямо в редакторе. У кнопки варианты и размеры выбираются по пропсам, а служебные `$variant` и `$size` не попадают в HTML. С CSS Modules я бы описал варианты отдельными классами и собирал их через `clsx`. Темы там можно было бы переключать через CSS-переменные и атрибут на `html`. CSS Modules убрали бы из этого проекта зависимость от библиотеки генерации стилей в браузере, а styled-components упростили общую типизацию темы и вариантность UI-кита.
